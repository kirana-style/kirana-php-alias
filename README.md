# kirana/kirana

The same package as [`kirana-style/kirana`](https://packagist.org/packages/kirana-style/kirana),
under a second name. It has no code of its own: installing it installs `kirana-style/kirana` at the
same version.

```bash
composer require kirana-style/kirana   # preferred
composer require kirana/kirana         # the same thing
```

Kirana for server templates: the class map reader, a Blade directive for Laravel and a Twig
function for Symfony. Documentation: https://kirana.style/docs/frameworks/server-templates

This repository is tagged together with `kirana-style/kirana`, one version for both.
